🔒 ClearJSON Privacy Policy

Last updated: July 2, 2026

ClearJSON is a browser extension that formats and displays JSON data. This policy explains what data we handle and why you can trust us.

1. What We Collect

Nothing. Zero.

  • ✓ No personal information
  • ✓ No browsing history
  • ✓ No analytics or telemetry
  • ✓ No crash reports
  • ✓ No cookies
  • ✓ No user accounts

ClearJSON processes everything entirely on your device. No data is ever sent to any server — not ours, not anyone else's. You can verify this by inspecting the extension's Network panel: it will be empty.

2. Permissions We Use

ClearJSON requests only the minimum permissions needed to function. Here's exactly what each permission does:

Permission Why We Need It
storage To save your theme preference and settings locally
activeTab To detect and format JSON in the current tab
Host permissions To detect Content-Type: application/json headers.
No page content is read unless the URL returns JSON.

3. What We Never Do

  • ✗ We never inject ads into your pages
  • ✗ We never track your browsing
  • ✗ We never send data to third parties
  • ✗ We never create user accounts
  • ✗ We never collect analytics
  • ✗ We never use fingerprinting or tracking scripts

4. Pro License Verification

If you purchase a ClearJSON Pro license, a one-time verification request is made to our license server (api.wayknow.tech) to validate your license key. This request contains:

  • Your license key
  • A random device identifier (not tied to your identity)
  • Your OS and Chrome version (for device management)

This is the only network request ClearJSON ever makes. It happens at most once every 7 days. No browsing data is included. Free users never make any network requests.

5. Open Source

ClearJSON is open source under the MIT license. Every line of code is publicly auditable at github.com/wayknow/clearjson.

We believe the strongest privacy policy is one you can verify yourself. If you find any behavior that contradicts this policy, please file an issue.

6. Changes to This Policy

If we ever change this policy, it will be reflected in the git history of our public repository. We will never silently change our data practices.

7. Contact

Questions or concerns? Open an issue on GitHub.
